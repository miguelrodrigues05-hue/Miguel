Atalhos Secretos do VS Code

Por: Miguel Luiz

Para programar mais rápido, experimente usar estes atalhos no seu dia a dia:

  • Shift + Alt + F: Formata o código inteiro.
  • Alt + Seta para Cima/Baixo: Move a linha.
  • Ctrl + /: Comenta a linha de código.

Esses atalhos podem ajudar a deixar o desenvolvimento mais rápido e organizado.

De onde veio o nome Bluetooth?

Por: Miguel Luiz

O nome Bluetooth tem uma origem curiosa.

Ele faz referência ao rei dinamarquês Harald "Bluetooth" Gormsson, conhecido por unir diferentes povos da região.

A escolha do nome faz uma comparação com a tecnologia, que também foi criada para conectar diferentes dispositivos.

Fonte: Bluetooth SIG

A história do primeiro mouse

Por: Miguel Luiz

O mouse é um dos dispositivos mais conhecidos da computação.

O primeiro protótipo foi desenvolvido por Douglas Engelbart durante pesquisas sobre interação entre pessoas e computadores.

O dispositivo ajudou a abrir caminho para formas mais simples de interagir com os computadores.
